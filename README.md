# ultema.pro — сайт Артёма Рякина

Статический сайт: чистый HTML / CSS / JS, без сборки и зависимостей. Папка `dist` — это готовый сайт целиком, её и выкладываем.

```
dist/
├── index.html                 главная (hero, работы, about, услуги, форма заявки)
├── projects/
│   ├── sky-race.html          полный кейс по структуре Behance
│   ├── esm-2026.html          каркас кейса + TODO-блоки, что дополнить
│   └── mercedes-autumn.html   каркас кейса + TODO-блоки
└── assets/
    ├── css/style.css          все стили
    ├── js/main.js             CONFIG (почта, telegram, ключ формы) + вся интерактивность
    ├── fonts/                 Michroma + Manrope (self-hosted, ~57 KB)
    ├── img/                   webp + jpg-фолбэк, постеры к видео
    └── video/                 H.264 mp4, пережаты под веб (все ~50 MB)
```

## Перед запуском — заполнить CONFIG

Открыть `assets/js/main.js`, в самом верху:

| Поле | Что вписать |
|---|---|
| `email` | реальная почта Артёма (сейчас `hello@ultema.pro`) |
| `telegram` | ник без @ — если пусто, кнопка Telegram скрыта |
| `web3formsKey` | ключ с https://web3forms.com (бесплатно: регистрируешь почту → получаешь access key). Пока пусто — форма открывает почтовый клиент с готовым письмом (mailto) |

## Как выложить на ultema.pro (статический хостинг)

Вариант A — **Cloudflare Pages** (рекомендую: бесплатно, быстрый CDN в РФ, https сам):
1. Залить `dist` в GitHub-репозиторий (можно как корень репо).
2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → выбрать репо, Build command пусто, Output dir `/` (или `dist`, если папка внутри).
3. Custom domains → добавить `ultema.pro` → прописать у регистратора DNS-записи, которые покажет Cloudflare.

Вариант B — **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / root. В корень положить файл `CNAME` с текстом `ultema.pro`, у регистратора: A-записи `185.199.108.153 … 111.153` + CNAME `www` → `<user>.github.io`.

Вариант C — обычный хостинг по FTP: просто залить содержимое `dist` в `public_html`.

Файлы `.webp/.mp4` кэшируются браузером; если хостинг позволяет — выставить `Cache-Control: max-age=31536000` для `/assets/*`.

## Фишечки, которые есть

- Hero-видео с зерном плёнки, поэтапное появление заголовка, периодический глитч, бегущая строка навыков.
- Карточки работ: при наведении играет превью-видео, 3D-наклон, свечение под курсором, маджента-шторка.
- Кастомный курсор (только десктоп с мышью), прогресс-бар чтения, липкая навигация по секциям кейса.
- Лайтбокс для сториборда / мудборда / стиллов (клавиши ←→, свайпы).
- Переключатель EN / RU (скрывает русские дубли), запоминается в браузере.
- Все видео `preload=none` + постер: грузятся только когда подъезжают к экрану, автоплей/пауза по видимости. Первая загрузка главной ≈ 300 KB без видео.
- На мобильных Behance-блоки с «вшитым» текстом (моделинг, сценарий, проблемы) заменяются на HTML-текст — читаемо на любом экране.
- `prefers-reduced-motion` — все анимации выключаются.

## Как добавить новый проект

1. Скопировать `projects/mercedes-autumn.html` → `projects/<slug>.html`, заменить тексты/пути.
2. Пережать видео: `ffmpeg -i in.mp4 -vf scale=1920:-2 -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart out.mp4`, постер: `ffmpeg -ss 3 -i out.mp4 -frames:v 1 poster.jpg`.
3. Добавить карточку в `index.html` в `.work-grid` и ссылки prev/next в соседних кейсах.
